# Capa Cero · datos

Datos que la app **Capa Cero** descarga sola una vez por semana:

- `version.json`: versión de cada archivo. La app solo descarga lo que sea más nuevo.
- `impresoras.json`: impresoras, materiales y perfiles base de Orca.
- `fallas.json`: base de fallas y soluciones.
- `calculadora.json`: costos estándar y referencias de mercado.

Al cambiar un archivo, sube su `version` y la misma en `version.json`.
